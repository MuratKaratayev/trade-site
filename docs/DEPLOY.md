# Переезд trade-engeeniring.kz на новый сайт

Составлено 2026-10-15 по скриншотам панели PS Cloud (Plesk) и по публичным DNS-записям домена.

## Что есть сейчас

| Что | Где |
| --- | --- |
| Старый сайт (MODX Revolution 2.7.2, PHP 7.4 — «устаревшая опция») | PS Cloud, Plesk, папка `httpdocs`, IP `195.210.46.34` |
| DNS домена | серверы PS Cloud: `ns1/ns2/ns3.ps.kz` |
| Почта `@trade-engeeniring.kz` | тот же сервер PS Cloud: `MX 10 mail.trade-engeeniring.kz` → `195.210.46.34` |
| SPF | `v=spf1 +a +mx include:_spf.ps.kz -all` |
| Новый сайт | Vercel, прод собирается из `main`: https://trade-194698d2-95f9-4939-b3b0-67fcf.vercel.app |

DNS-записи на 2026-10-15 (через `dns.google`): `@ A 195.210.46.34`, `www CNAME trade-engeeniring.kz`,
`mail A 195.210.46.34`. Записи DKIM и DMARC не проверялись.

## Рекомендуемый вариант: сайт на Vercel, почта остаётся на PS Cloud

Сайт — приложение Next.js: заявки через Server Action, редиректы и заголовки безопасности из `next.config.ts`,
оптимизация картинок. На Vercel всё это уже работает. Меняются только две DNS-записи сайта,
почта и старый хостинг не затрагиваются.

### Шаги

1. **Резервная копия старого сайта.** Plesk → домен → «Резервное копирование и восстановление».
   Скачать копию файлов и базы MODX себе.
2. **Заранее (за сутки) уменьшить TTL** записей `@` и `www` до 300 с.
   Plesk → «Хостинг и DNS» → DNS или личный кабинет ps.kz. Тогда откат займёт минуты.
3. **Добавить домен в Vercel.** Project → Settings → Domains: `trade-engeeniring.kz` и `www.trade-engeeniring.kz`.
   Один из них назначить основным, второй — с редиректом на основной.
   Vercel покажет точные записи. Обычно это `A 76.76.21.21` для корня и `CNAME cname.vercel-dns.com` для `www`.
   Ставить те значения, которые покажет Vercel.
4. **Поменять в DNS (PS Cloud) только эти две записи:**
   - `trade-engeeniring.kz.  A  195.210.46.34` → IP из Vercel;
   - `www  CNAME trade-engeeniring.kz.` → CNAME из Vercel.

   **Не трогать:** `MX`, `mail`, `TXT` (SPF), записи DKIM/`_dmarc`, `autodiscover` и прочие почтовые записи.
   SPF продолжит пропускать почту сервера через `+mx`, потому что `mail` по-прежнему указывает на `195.210.46.34`.
5. **Дождаться SSL.** Vercel сам выпустит сертификат, когда увидит новые записи (обычно минуты).
6. **Проверить:**
   - `https://trade-engeeniring.kz/` и `https://www.trade-engeeniring.kz/` открывают новый сайт;
   - старые URL дают один 301 (список — в `next.config.ts`);
   - почта ходит в обе стороны (отправить и получить письмо).
7. **Старый сайт** остаётся на PS Cloud как резерв. Если нужен доступ к нему — завести в Plesk поддомен,
   например `old.trade-engeeniring.kz`. Позже хостинг сайта у PS Cloud можно сократить до почты.
   MODX 2.7.2 устарел, панель показывает уведомления безопасности, так что держать его открытым надолго не стоит.

**Откат:** вернуть `@ A 195.210.46.34` и `www CNAME trade-engeeniring.kz.` При TTL 300 откат займёт минуты.

### До переключения домена (в коде)

- Убрать с сайта видимые плейсхолдеры `[ОТ КЛИЕНТА: …]`: «Средства автоматизации», сроки изготовления шкафов.
  Также `/privacy` — черновик, нужна юридическая проверка.
- Решить, куда уходят заявки: сейчас форма их не сохраняет.
- `company.url` в `content/site.ts` уже `https://trade-engeeniring.kz`: canonical, sitemap и OG будут верными.

## Альтернатива: статика на PS Cloud (не рекомендуется)

`next build` с `output: 'export'` → загрузить `out/` в `httpdocs` через FTP или Git из Plesk. Минусы:

- не работают Server Action (форма заявок), редиректы и заголовки из `next.config.ts`;
- не работает оптимизация `next/image`.

Всё это пришлось бы переделать: форму через внешний сервис, редиректы и заголовки через `.htaccess`/nginx.
Обновления — вручную после каждой сборки. Поддержки Node.js на этом тарифе в панели не видно:
есть PHP, WordPress, Laravel и Joomla, без Node.js. Запускать Next.js как сервер у PS Cloud, вероятно, нельзя —
это нужно уточнить у них.
