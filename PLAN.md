# План редизайна trade-engeeniring.kz

Документ от 2026-10-13. Основан на осмотре старого сайта https://trade-engeeniring.kz/
(скачаны и разобраны 10 страниц, сделаны скриншоты 1440 px и 390 px).

## 1. Что сейчас на старом сайте

**Структура (10 страниц):**
Главная · О компании · Продукция (4 категории + «Аналитические приборы жидких сред») ·
Услуги · Наш опыт (3 страницы пагинации) · Контакты.

**Контент, который стоит сохранить:**
- Чёткое позиционирование: интегратор АСУ ТП полного цикла (обследование → проект →
  поставка КИПиА → шкафы → СМР → пусконаладка и сервис).
- Реальные проекты с фотографиями: ПНС-2/3 («Павлодарэнерго»), «Шубарколь Комир»,
  КЭЗ (3D-сканеры Rosemount), «Алюминий Казахстана», «Казсода», «Казхром».
- Заказчики: ERG (АО «Алюминий Казахстана», АО «ТНК Казхром», АО «КЭЗ»,
  АО «Шубарколь Комир»), АО «Павлодарэнерго», АО «Астана-Энергия», АО «ПНХЗ»,
  Таразский металлургический завод, ЖГРЭС и др.
- Сертификаты, лицензии, отзывы заказчиков (сканы).
- Каталог: контроллеры TREI-5B, КИП Emerson (Rosemount, Micro Motion, Daniel), шкафы.

**Предположения (не проверено, уточнить):**
- CMS, скорее всего, **MODX Revolution**: в `robots.txt` есть `/manager/`, `/core/`,
  `/connectors/`, а в путях — `/assets/components/ajaxform/`. Это типичная структура MODX,
  но доступа к админке у нас нет.
- В домене опечатка: `engeeniring` вместо `engineering`. Смена домена — решение клиента
  (риски: SEO, почта `info@`). Без согласования домен НЕ меняем.
- Из БИН `160840…` можно предположить регистрацию в августе 2016 года: в казахстанском БИН
  первые цифры — год и месяц. Это догадка, на сайт её не выносим без подтверждения.

## 2. Цели нового сайта
1. Внятное УТП с первого экрана: «АСУ ТП под ключ» + доказательства (проекты, заказчики, сертификаты).
2. Заявка в один шаг с любой страницы; ушла заявка — уведомление менеджеру.
3. Скорость и SEO: статическая генерация, оптимизированные изображения, мета-теги,
   `sitemap`, микроразметка `Organization`.
4. Современный вид: светлая и тёмная тема, аккуратный моушн, корректная работа на телефоне.
5. Простое обновление контента (проекты, каталог) без программиста — см. этап 4.

## 3. Стек (выбран для прототипа)
- **Astro 7** (статическая генерация; JS шлётся только туда, где нужна анимация).
  Версия закреплена (`astro@7.3.5`).
- Чистый CSS с токенами (`src/styles/global.css`) без UI-фреймворков.
- Моушн — CSS-анимации, SVG `<animateMotion>` и немного ванильного JS
  (IntersectionObserver, requestAnimationFrame). Без GSAP: для текущих эффектов он не нужен.
- Шрифты Onest и JetBrains Mono, self-hosted через `@fontsource` (есть кириллица).
- Хостинг: **не решено**. Варианты: Vercel или Netlify для превью и (или) прода,
  либо выгрузка статики на текущий nginx клиента.

## 4. Этапы

### Этап 1 — прототип для согласования (сделан в этой ветке)
- [x] Главная с моушн-дизайном:
  - анимированная схема АСУ ТП в hero: датчики → контроллер TREI → SCADA, бегущие сигналы,
    «живые» показания и тренд (значения декоративные);
  - построчное появление заголовка;
  - счётчики фактов;
  - линия «полного цикла», заполняемая при скролле;
  - 3D-наклон карточек продукции;
  - лента проектов;
  - схема географии с дугами от Павлодара;
  - бегущая строка заказчиков.
- [x] Страница «Услуги» (шаблон внутренних страниц).
- [x] Переключатель темы: «как в системе» (по умолчанию) / светлая / тёмная. Выбор
  запоминается, темы переключаются без мигания, режим «как в системе» реагирует на смену темы ОС.
- [x] `prefers-reduced-motion`: при включённой настройке анимации отключаются.
- [ ] Выложить превью по ссылке для клиента (нужно решение по хостингу).

### Этап 2 — согласование с клиентом
Запросить и получить:
- векторный логотип (SVG, AI или PDF). Сейчас в прототипе **временная заглушка**;
- фирменные цвета (сейчас акцент `#c8320f` подобран по логотипу и старому CSS `#d73313`);
- подтверждение фактов: год основания, статус дилера TREI (на старом сайте есть скан
  «Сертификат дилера ТРЕИ 2023»), актуальный список заказчиков и проектов;
- фото проектов в хорошем качестве, сертификаты и отзывы в PDF;
- куда слать заявки (почта, Telegram, CRM?);
- нужен ли казахский и (или) английский язык.

### Этап 3 — остальные страницы
О компании (сертификаты, лицензии, отзывы) · Проекты (список + страница проекта) ·
Продукция (категории + карточки) · Контакты (карта, реквизиты) · 404 · Политика
обработки персональных данных.

### Этап 4 — контент и форма
- Перевести проекты и каталог в Astro Content Collections (Markdown или JSON в репозитории).
  Если клиент хочет править сам — подключить headless-CMS (Decap, Sanity и т. п.);
  выбрать вместе с клиентом.
- Форма заявки: серверная функция (Vercel или Netlify) или сторонний сервис →
  почта и (или) Telegram. Защита от спама (honeypot и др.).

### Этап 5 — перенос и запуск
- 301-редиректы со старых URL (`/o-kompanii`, `/produkcziya/...`, `/nash-opyit/`,
  `/kontaktyi`, `/uslugi/`) на новые.
- SEO: `title` и `description` на каждой странице, Open Graph, `sitemap.xml`,
  `robots.txt`, JSON-LD `Organization`.
- Удалить `<meta name="robots" content="noindex">` (сейчас стоит, потому что это прототип).
- Lighthouse ≥ 90 по всем категориям; проверка в Safari, Chrome, Firefox и на мобильных.
- Аналитика: Яндекс Метрика и (или) GA — по выбору клиента.
