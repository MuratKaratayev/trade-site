# trade-site

Новый сайт ТОО «TRADE-Инжиниринг» (замена https://trade-engeeniring.kz/) по согласованному брендбуку.
Next.js 16 (App Router, TypeScript) · Tailwind CSS v4 + CSS-токены · деплой на Vercel.

```sh
npm install
npm run dev        # http://localhost:3000
npm run build      # production-сборка
npm run start      # запуск сборки
npm run typecheck
```

- Брендбук (источник правды): `docs/brandbook/TRADE-brandbook.dc.html`;
  скрипт моушн-фигур: `docs/brandbook/Brand-03-Motion.script.js`.
- Весь контент: `content/site.ts`. Строки `[ОТ КЛИЕНТА: …]` выводятся видимыми плейсхолдерами.
- План и статус: [PLAN.md](PLAN.md) · контекст для следующих сессий: [HANDOFF.md](HANDOFF.md)
