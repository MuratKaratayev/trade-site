# trade-site

Новый сайт ТОО «TRADE-Инжиниринг» (замена https://trade-engeeniring.kz/). Сейчас это прототип
для согласования с клиентом: главная (с моушн-дизайном) и «Услуги».

```sh
npm install
npm run dev      # http://localhost:4321
npm run build    # статика в dist/
```
